Hyper City Parkour is a 3D platformer with parkour elements, developed and published by Octobus Game.

Key game details:

• Platform: Windows (available for download on ModDB and itch.io).

• Main character: You play as a robot on wheels whose goal is to get home by jumping from rooftop to rooftop throughout the city.

• Story/Gameplay: The journey takes place not only in the city but also across various themed planets (a tropical island, lava mountains, a snowy world), after which the protagonist returns home to find the city in ruins under attack.

• Update/Release Date: The active versions and game files were updated in May 2026.
